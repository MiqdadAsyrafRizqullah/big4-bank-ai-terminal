# 💹 AI Trading Terminal 2.0: Analisis Komprehensif & Peramalan Saham Big 4 Bank Indonesia

Sistem Data Science dan Pipeline Data otomatis untuk analisis teknikal, indikator makroekonomi, dan peramalan harga saham Big 4 Bank (BBCA, BBRI, BMRI, BBNI) menggunakan algoritma **Ridge Regression**.

## 📌 Fitur Utama
1. **Pipeline Data Otomatis:** Orkestrasi ETL menggunakan Apache Airflow untuk ekstraksi harian dari Yahoo Finance & World Bank.
2. **Database Star Schema:** Desain skema bintang di MySQL terpusat untuk efisiensi kueri analitik.
3. **Exploratory Data Analysis (EDA):** Analisis tren 16 tahun (2010–2026), volatilitas boxplot, dan heatmap korelasi.
4. **Machine Learning Engine:** Model Ridge Regression (L2 Regularization) dengan akurasi ilmiah $R^2 > 0.99$ dan MAPE < 1%.
5. **Dashboard Interaktif Streamlit:** Visualisasi Candlestick interaktif, analisis risiko makro, prediksi 30 hari bursa, dan evaluasi model.
